# Travel Journal System

Use this reference for Mooselog-style 旅行手帐 / travel journal pages.

## Product Definition

A travel journal page is a **designed editorial notebook spread**. It combines practical guide information, illustrated route storytelling, photos, local context, checklists, and hand-crafted visual texture.

The goal is not to show every photo. The goal is to make the trip feel understandable, collectible, and visually authored.

## Reference-Image Structure

For a reference like the Kawagoe page, learn the layout grammar:

- **Notebook sheet**: visible paper texture, slight skew, binding holes, folds, tape, stamps, pencil marks, and imperfect ink.
- **Header block**: day label, date, large title, subtitle, small location illustration.
- **Top info cards**: weather, local knowledge, today goals. Keep cards compact and distinct.
- **Schedule column**: a vertical numbered timeline with time ranges, stop names, short notes, icons, and practical tags.
- **Map field**: a large illustrated map with pale roads/trails, colored dotted route line, arrows, numbered pins, and landmark sketches.
- **Stop callouts**: small cards attached to route pins with time, stop name, short description, and 1-2 tags.
- **Map labels**: when the user prioritizes a quiet map, use the map's own paper label pockets and show only Chinese/English place names.
- **Bottom utility area**: food list, check-in list, transport guide, budget/ticket/reservation notes, and tips.
- **Footer strip**: optional day slogan, tomorrow teaser, or source/update note.

## Composition Principles

1. Start with a page architecture, not with photos.
2. Establish two or three dominant zones. Avoid equal-weight boxes everywhere.
3. Use asymmetry: one large map panel, one structured schedule panel, and several smaller support cards.
4. Keep the page dense, but make density organized by lines, color, spacing, and labels.
5. Let route color and numbered pins connect the map side to the schedule side.
6. Keep practical information short; use tags and checkboxes instead of paragraphs.
7. Use illustrations/stickers only when they identify a stop, food, transport, weather, gear, or mood.

## Recommended Architectures

### A. Classic Split Journal

Use for one-day citywalks or daily guide pages.

- Top 15-18%: header and three info cards.
- Left 35-45%: schedule column.
- Right 45-55%: map field.
- Bottom 18-25%: utility cards.

For multi-day Xiaohongshu pages using this architecture, the split is continuous from top to bottom:

- Left 42-48%: title/date, weather, knowledge, key information, itinerary grouped by day, wish list, and transport guide.
- Right 52-58%: map artwork only, plus route, pins, landmark illustrations, and concise stop labels.
- Keep all long-form practical copy on the left. The right side should remain a visual journey field.

### B. Hiking Field Journal

Use for mountain routes.

- Top: title, weather/safety/route summary.
- Middle: large trail map plus route phase cards.
- Side or lower column: schedule and difficulty notes.
- Bottom: gear checklist, reservation/parking card, safety card, map links.

### C. Photo Memory Journal

Use when photos are emotionally important.

- One large hero photo or illustration.
- Smaller route/map strip.
- Handwritten notes and stickers.
- Fewer practical cards.

### D. Magazine Notebook Guide

Use for high-design, less cute outputs.

- Cleaner margins.
- Fewer icons.
- Strong typographic hierarchy.
- Map and photos treated as editorial graphics.

## Visual Language

- Paper: warm off-white, light cream, subtle fibers, notebook lines, map grid, faint stains, tape, torn edges.
- Linework: imperfect ink, pencil, watercolor contour, colored-pencil map roads, dotted route line.
- Color: use 3-5 recurring soft colors. Assign each color a job: route, alert, food, transport, nature, photo.
- Palette coupling: sample information-card fills and borders from the illustrated map so both halves feel printed on one page.
- Typography: combine bold handwritten-style Chinese headings with readable body text. Keep body copy phone-legible.
- Icons: small and content-specific. Use camera, train, car, cable car, weather, food, ticket, warning, parking, backpack, checkmark.
- Photos: use as stickers, stamps, small postcards, clipped evidence, or sketch references. Avoid a photo wall.

## Information Rules

Each page should usually contain:

- title;
- day/date or route label;
- 3-6 stops or route phases;
- schedule or route order;
- illustrated map or route field;
- practical info cards;
- at least one checklist;
- map links/coordinates/source notes when supplied;
- one short mood line or subtitle.

For each stop, include:

- number;
- time or phase;
- name;
- one action/reason;
- 1-2 tags.

For time-sensitive claims:

- Browse official/current sources when the user asks for research.
- State "出发前确认" for weather, opening hours, prices, road status, reservations, and operating windows when uncertain.
- Do not invent exact numbers.

## Photo Transformation Guidance

Use user photos to create:

- landmark sticker;
- small framed postcard;
- watercolor/colored-pencil landmark sketch;
- cutout silhouette;
- faded background patch;
- tiny "photo proof" card.

Do not enlarge every photo equally. Do not let photos occupy more than half the page unless the mode is `photo-memory-journal`.

When the user asks for complex hand drawing, photo transformation is mandatory. A photo inside a sketched border is still a photo. Convert the subject into a shared watercolor, colored-pencil, ink, or gouache language, and remove photographic lighting/detail from the final map field.

## Map Guidance

Build an illustrated map field:

- pale roads/trails as low-contrast network;
- terrain/trees/water/urban blocks as simple repeated marks;
- route as bright dotted/dashed path with arrows;
- numbered pins matching the schedule;
- stop callouts placed along the path;
- small landmark illustrations or photo stickers attached to important stops.

Do not paste raw Google Maps as the design. If using Google Maps links, show them as source cards, QR placeholders, or map-link footnotes.

Create the illustration layer before the typography layer. Reserve quiet label pockets beside each landmark, then place text only inside those pockets. Run a collision check so routes, pins, flags, and landmark detail do not enter label rectangles.

When the map artwork already includes paper label pockets, do not cover them with new oversized cards. Place only Chinese and/or English destination names inside the existing pockets. Use a single muted ink color for label borders and route marks unless color encodes essential route grouping.

For international trips, add a subtle destination-country flag watermark in the upper-right map area at roughly 6-14% opacity unless the user opts out.

## Content Iteration

Treat each left-side module as editable data: title, weather, knowledge, key information, day itinerary, wish list, and transport guide. When the user changes one module, preserve the approved map, composition, palette, and typography; reflow and collision-check only the affected content region.

## Quality Bar

Before final delivery, verify:

- Does it read as a travel journal page at first glance?
- Is the structure closer to a notebook guide than to a collage, poster, or dashboard?
- Is there a clear title, route/map, schedule/order, and utility information?
- Are photos subordinate to the designed page system?
- Are visual modules varied in size and role?
- Are map pins and schedule numbers synchronized?
- Is the page beautiful enough to save, not merely informative?
- Is text legible on a phone?
