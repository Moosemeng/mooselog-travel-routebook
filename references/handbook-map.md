# Handbook Map Alias

`handbook-map` is a legacy V1.1 name. In V2.0, treat it as an alias for [travel-journal-system.md](travel-journal-system.md).

When the user asks for `handbook-map`, 手帐式路书, 手账路书, 攻略地图, or shares a notebook-map reference, read `travel-journal-system.md` and produce a complete travel journal page, not a photo collage or plain route map.
