# Style Presets

Use one primary journal mode and one secondary surface style. Do not combine many styles in one page.

## V2.0 Journal Modes

### travel-journal

Default for most requests. Best for Xiaohongshu travel notes, all-in-one guide pages, daily itinerary pages, and reference images with rich notebook layout.

- Build a complete designed notebook page, not a route map with decoration.
- Use title, date/day tag, schedule, map panel, stop cards, info cards, checklists, transport/tip modules, and visual stickers.
- Use photos sparingly as evidence stickers or illustration references.
- Keep the page dense but intentional: every module must have a role.

### illustrated-map-journal

Best when the user wants the map to be the emotional center.

- Make the illustrated map panel largest.
- Use colored dotted routes, hand-drawn roads/trails, arrows, pins, small landmarks, and route callouts.
- Keep schedule/tips visible but secondary.

### hiking-field-journal

Best for mountain, trekking, road-trip, ski, camping, or outdoor guide pages.

- Emphasize distance, duration, climb, difficulty, gear, weather, parking, reservations, safety, and route phases.
- Use terrain marks, contour-like lines, trail ribbons, warning tags, and equipment checklist modules.
- Photos can become landmark stickers, viewpoint cards, or route evidence.

### photo-memory-journal

Best for emotional travel memory pages rather than practical guide pages.

- Allow larger photos, handwritten notes, ticket stubs, stamps, dates, and memory fragments.
- Keep route/order present but quiet.
- Use fewer practical modules.

### minimal-guide-card

Best when clarity and quick reading matter more than hand-drawn charm.

- Use clean grid, fewer decorations, clear hierarchy, concise text, and map/route summary.
- Keep visual texture light.

## Surface Styles

Before selecting a surface style, apply the adaptive destination palette. For domestic China, also select a regional Chinese visual dialect; the surface style is secondary to that cultural and geographic decision.

### cute-handbook

Soft, cheerful, and highly shareable.

- Use warm paper, rounded cards, soft shadows, hand-drawn icons, pastel route colors, tape, stickers, and friendly typography.
- Good for citywalk, food, friends, family, and Xiaohongshu guide pages.

### elegant-travel-notes

More restrained and design-led.

- Use neutral paper, careful spacing, small editorial typography, muted accents, thin ink lines, and balanced white space.
- Good for architecture, museums, slow travel, high-end travel journals, and portfolio-like posts.

### vintage-postcard

Nostalgic and archival.

- Use stamps, postal marks, faded ink, warm sepia/blue/red, typewriter text, ticket fragments, and old-paper texture.

### watercolor-travel

Soft and scenic.

- Use translucent washes, colored pencil, airy map marks, light hand lettering, and photo-derived landscape sketches.

### contemporary-chinese-travel

The default surface direction for domestic China when no narrower direction is requested.

- Use region-specific Chinese editorial grammar, not a generic ancient-paper costume.
- Combine contemporary information design with selected album-leaf, handscroll, local-gazetteer, printmaking, mineral-color, ink, seal, ticket, or folded-map structures.
- Read [china-travel-visual-system.md](china-travel-visual-system.md) and select only motifs supported by the destination.

### gathered-zine

Art-poster adjacent.

- Use truthful photo anchors, paper collage, structural color, torn edges, and quiet negative space.
- Use when the user asks for "高级", "杂志", "拼贴", or artful editorial feeling.

### risograph-poster

Bold design post.

- Use 2-3 ink colors, overprint, grain, misregistration, graphic route shapes, and poster-like hierarchy.

## Legacy Aliases

- `handbook-map` -> `travel-journal` or `illustrated-map-journal`
- `cute-comic` -> `travel-journal` with `cute-handbook`
- `sticker-journal` -> `photo-memory-journal` or `travel-journal` with `cute-handbook`
- `minimal-map` -> `minimal-guide-card`
- `routebook` -> journal page with route module

## Selection Rules

- If the user says "旅行手帐", "手账", "手帐式", "参考这张图", "设计感", "小红书攻略图", choose `travel-journal`.
- If the user wants the map side to dominate, choose `illustrated-map-journal`.
- If the trip is hiking/outdoor and needs safety, parking, equipment, or reservation notes, choose `hiking-field-journal`.
- If the user mainly wants beautiful memories from photos, choose `photo-memory-journal`.
- If the page must be very readable or official-looking, choose `minimal-guide-card`.
- If the user says "可爱" plus "攻略/地图/行程", choose `travel-journal` with `cute-handbook`, not `cute-comic`.
- If the user says "高级/杂志/拼贴", choose `gathered-zine` as the surface style.
