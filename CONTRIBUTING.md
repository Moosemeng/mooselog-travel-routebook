# Contributing

Thank you for helping improve Mooselog Travel Routebook.

1. Open an issue describing the travel-journal scenario and observed problem.
2. Keep changes focused and preserve progressive disclosure between `SKILL.md` and `references/`.
3. Keep user photos, personal data, booking details, and generated test output out of the repository.
4. Preserve the original license files when adding or replacing fonts or other third-party assets.
5. Run the Codex skill validator before opening a pull request.

By contributing, you agree that your contribution is licensed under the repository's MIT License, except for third-party assets that carry their own compatible license.
